声态 · Android

隐私政策

声音设置

声态在设备上读取媒体、铃声、闹钟音量和当前响铃模式，用于显示状态并执行你的调整。应用不使用麦克风，不录音，也不读取通知内容。

权限和后台控制

部分设备需要勿扰模式使用权才能进入或退出静音。开启后台磁贴控制后，声态运行前台服务，并使用通知权限显示运行状态。你可以在应用内关闭此功能，也可以在系统设置中撤销权限。

存储、共享与删除

布局偏好和快捷设置磁贴状态保存在应用专用存储中。Android 可能按系统设置备份或迁移布局偏好；应用的备份规则排除了快捷设置磁贴偏好。你可以在系统设置中清除声态的应用数据，或卸载应用以删除本地应用数据。系统音量由 Android 管理。

收集与第三方

应用无需注册账户。开发者不接收或出售你的声音设置或应用偏好，也不会将其分享给广告商或分析服务商。应用不含广告或统计分析 SDK。

关于本站

本站由 GitHub Pages 托管。GitHub 会出于安全目的记录访客 IP 地址。下载和支持链接也会打开 GitHub。 GitHub 隐私声明.
